# SarvVivah - All Caste Matrimonial Portal

**Tagline:** One Platform. All Castes. One Life Partner.

## Overview

SarvVivah is a centralized, caste-inclusive matrimonial platform designed to serve users across all castes, religions, and communities under a single unified system.

## Technology Stack

- **Frontend:** React with JavaScript
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Animations:** Framer Motion
- **Forms:** React Hook Form
- **HTTP Client:** Axios

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm start
```

Runs the app in development mode at [http://localhost:3000](http://localhost:3000)

### Build

```bash
npm run build
```

Builds the app for production to the `build` folder.

## Features

- User Registration & Authentication (OTP-based)
- Profile Creation (Personal, Caste, Education, Professional, Family, Horoscope)
- Photo Management
- Partner Preference Settings
- Search & Match Engine
- Interest Management
- Messaging System
- Admin Control Panel
- Role-based Access Control
